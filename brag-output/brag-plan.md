# Brag Plan: ScopeShift

## What is this app?
ScopeShift is a deterministic, evidence-governed requirements engineering platform that decouples multi-modal AI extraction from specification authority through code-level citation proofs and tamper-evident event streaming.

## The angle
"Seeing a button is not approving the button." In modern multi-agent systems, unverified staging UI mocks or chat snippets get hallucinated into requirements specifications. ScopeShift enforces a fail-closed cryptographic boundary where only verified client authority can govern.

## Hook (first 2-3 seconds)
A dynamic 3D spatial twin with a glowing red vector clash barrier:
"In multi-agent systems, seeing a button in a screenshot gets mistaken for scope approval."

## Key moments (the middle)
- **Moment 1 (3-8s):** Decoupling Extraction from Authority. Gemini extracts structured claims, but pure deterministic Python enforces citation integrity. Fabricated quotes fail closed with rejection receipts.
- **Moment 2 (8-14s):** Visual Provenance Diff Inspector. Side-by-side evidence cards showing baseline requirements vs staging observations with pixel bounding overlays.
- **Moment 3 (14-19s):** 1-Click Scenario Execution. Verified client directive instantly promotes the disputed claim to GOVERNED with monotonic event ordering.

## Outro / punchline (19-24s)
The tamper-evident SHA-256 event ledger streaming to BigQuery:
"Every requirement cryptographically proven. Zero drift. ScopeShift."

## User flow worth showing
1. Staging screenshot introduces "Card Payment" conflicting with UPI-only BRD -> Marked `DISPUTED` with physical red barrier in 3D twin.
2. Clicking the state banner opens the Visual Provenance Diff Inspector displaying verbatim quotes.
3. Client authorization note arrives -> State advances deterministically to `GOVERNED`.
